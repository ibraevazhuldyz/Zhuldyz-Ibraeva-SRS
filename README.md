Ибраева Жулдыз

Бұл жұмыста Patient класы жасалды. Клас пациенттің атыжөнін, жасын, диагнозын, температурасын өлшемдерін сақтайды. Класта инкапсуляция қолданылды және өрістер private болыяп жазылды. Getter, setter әдістері арқылы жұмыс жасалды. Температуралар динамикалық массивте сақталды. Көшірме конструктор арқылы мәліметтер көшірілді, деструктор динамикалық жадты босатады. this, const, =,== операторлары қолданылды.
